# سایت Jekyll تسمه بزرگمهر

- فایل‌های مشترک قالب در `_layouts/default.html` و `_includes/` قرار دارند.
- صفحات اصلی، محصولات و وبلاگ در فایل‌های جدا باقی مانده‌اند.
- شماره تماس، واتساپ و اینستاگرام به صورت دکمه شناور اضافه شده‌اند.
- برای آزمایش محلی: `bundle install` سپس `bundle exec jekyll serve`
- در GitHub Pages، سورس را در مخزن قرار دهید و تنظیمات Pages را مطابق روش انتشار Jekyll انتخاب کنید.

قبل از انتشار، سایت را با `bundle exec jekyll build` بررسی کنید.
